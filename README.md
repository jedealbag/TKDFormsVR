# TKDFormsVR 🥋

Prototipo WebXR para practicar poomsae (formas) de taekwondo en Meta Quest.

## Probarlo
Abre la página publicada en el navegador del Meta Quest y pulsa **Entrar a VR**.

## Cómo funciona
- Instructor fantasma que demuestra cada técnica de Taegeuk Il Jang (18 movimientos)
- Esferas de luz como zonas objetivo para las manos (y el pie en patadas)
- Verificación de postura (Ap Kubi) y giros
- Modos: Aprender y Pasada con cadencia

## Nota técnica
Debe servirse como página de nivel superior (no dentro de un iframe sin `allow="xr-spatial-tracking"`) para que WebXR funcione. GitHub Pages la sirve directo. ✅
